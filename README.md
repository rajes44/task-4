# Task 04 — Responsive Dashboard

A standalone responsive dashboard demonstrating CSS design tokens, CSS Grid, Flexbox, breakpoints, and light/dark theme variables.

## Run
Open `index.html` in a browser. No build tools required.

## Proof checklist
- [ ] Test at 320px, 480px, 768px, 1024px and desktop.
- [ ] Confirm no horizontal scrollbar at mobile widths.
- [ ] Toggle the light/dark theme.
- [ ] Capture desktop and mobile screenshots for the task submission.

## Main files
- `style.css`: design tokens, responsive layout and theme variables.
- `script.js`: theme toggle.
